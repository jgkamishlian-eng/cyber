Raspberry Pi 3B+ Security Console

Quick shortcuts for common automation tasks and diagnostics.

Offline Safe Mode Local Scripts

Internet Check (Defensive)

Validate connectivity and DNS resolution.

ping -c 4 8.8.8.8

Password Audit

Run a local password audit with a wordlist.

sudo john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

Fast Port Discovery

Quickly identify open ports on a target.

sudo nmap -T4 -F 192.168.1.0/24

Web Scan

Run a focused web scan against discovered HTTP services.

./scripts/automation-shortcut.sh nmap-nikto 192.168.1.10 ./captures

Subdomain Enumeration

Map discovered subdomains and scan them.

./scripts/automation-shortcut.sh amass-nmap example.com ./captures -- -sV -T4

SSL/TLS Scan (Defensive)

Check TLS configuration and supported ciphers.

nmap --script ssl-enum-ciphers -p 443 example.com

Wireless Scan (Defensive)

List nearby wireless networks and signal strength.

sudo iwlist wlan0 scan | grep -E "ESSID|Quality"

Listening Mode (Defensive)

Watch incoming traffic on an interface.

sudo tcpdump -i eth0 -nn

Wi-Fi Kill Switch (Defensive)

Kick clients off a Wi-Fi network (authorized testing only).

sudo aireplay-ng --deauth 25 -a AA:BB:CC:DD:EE:FF wlan0mon

VoIP Capture (Defensive)

Capture SIP/RTP traffic for VoIP analysis.

sudo tshark -i eth0 -f "udp port 5060 or udp portrange 10000-20000" -w voip.pcapng

Packet Capture

Capture network traffic during a scan.

sudo ./scripts/automation-shortcut.sh nmap-wireshark 192.168.1.0/24 eth0 ./captures

Vulnerability Scan

Run Nmap vuln scripts against a target.

sudo nmap --script vuln 192.168.1.10

Wi-Fi Password Audit

Recover Wi-Fi keys from a captured handshake (authorized only).

aircrack-ng -w /usr/share/wordlists/rockyou.txt -b AA:BB:CC:DD:EE:FF capture.cap

Bluetooth Pairing Audit

Test BLE pairing captures for weak keys (authorized only).

crackle -i ble-capture.pcap

NFC Key Audit

Recover MIFARE Classic keys from authorized tags.

mfoc -O tag-dump.mfd -P 500

Tip: Update target IPs, domains, and interfaces before running commands.
